## Контекст прогона (находки вне тестов — не блокируют AC, требуют действий вне QA)

1. **Запись `Contract:` в `plugins/gramax/CHANGELOG.md` отсутствует в дереве** (NFR-068/ADR-0024 Решение 3, «Миграция» п. 5 — «тем же коммитом»). `grep -nE 'schemaVersion|W035|diagramTags' plugins/gramax/CHANGELOG.md` — только историческая `schemaVersion 1`; `git show --stat 6d43b7d` CHANGELOG не содержит. Dev объявил перенос явно: «CHANGELOG Contract: — PM-пакетом» в сообщении коммита. Это отклонение от буквы NFR-068 — процессная часть, тестом не покрывается (прецедент AC-007 «процессная, не автоматизируется»). Действие для PM: запись Contract: (schemaVersion 2, ключ `diagramTags`, код W035) обязательна до release — иначе потребители останутся без объявленного изменения публичного контракта вывода.
