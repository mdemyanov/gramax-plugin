(`plugins/gramax/scripts/migrate_mermaid.py:92–107`), а `.doc-root.yaml` фикстуры переехал
вместе с каталогом (пара `{content => docs}` в `git show --stat 2e9c86b` — нулевой диф).

трёх находках, счётчик `To-migrate: 3`, три строки путь:строка против нового имени, DSL
побайтово, дефолтные теги, идемпотентность) — диф стаба меняет только литерал имени каталога
(`git show 2e9c86b -- tests/gramax/mermaid-adoption/ac-187-multiple-legacy-blocks.sh`).
