# Запись замера калибровки validate_render против факта рендера (FR-196) — эпик Playwright render probes

**Дата:** 2026-11-21. **Цель рендера:** внутренний портал (хост — данные цели,
`render-target.local.json` вне git; литерал не публикуется — ADR-0014), каталог
`gramax-user-docs` — временный приём по санкции владельца: 21 страница запушена коммитом
`9aef498`, удалены после замера коммитом `94e3068` (окно присутствия ~25 минут);
постоянный выделенный каталог `render-probes` — предмет владельца (runbook, раздел пуша).

**Протокол (FR-196):** tier-0 проба прибора (`probe.sh`, `--retry 2 --retry-wait 5`) и
`validate_render` по одним и тем же 21 фикстурам; `invalid-utf8.md` исключён из прогона
валидатора (порт без UTF-8-защиты — факт 4 RES-009; полуфабрикат запрещён FR-198).
Валидатор до замера: rc=1, 8 ERROR в 6 файлах из 20. tier-0: 16 match / 5 divergence.
Полный отчёт пробы — `tests/gramax/render-quality/results/real-target-report.md` (вне
git, каталог результатов игнорируется). A/B-твиновская нога («200 после») отработана
парами `*-ok` (коммит 2dd9327).

## Разбор расхождений до источника

Пять divergence-фактов разбора на три класса: (1) **реальные 500-киллеры этого
инстанса** — `colgroup-multiline`, `note-inline`; (2) **деградация-не-500** —
`unbalanced-pair-tags`, `multiple-images`: симптом не воспроизведён даже грубой пробой
HTML, судить может только tier-1 DOM-ассерт (нужен `pageUrlTemplate` — данные владельца);
(3) **дрейф рендерера** — `th`, `xml-in-html-comment`, `tag-fragment-tail`: правила,
подтверждённые апстримом 04.09.2026 на их корпусе, дают 200 на текущей версии этого
инстанса. Следствие для протокола: ERROR-статус правила правомерен только при факте 500
на СВОЕЙ цели — апстрим-таблица является гипотезой до локального подтверждения (BR-021,
RES-009 §5).

## Решения (код + запись одним коммитом, FR-196)

1. `validate_render.py`: note-in-cell → WARN, note-in-note → WARN (тексты сообщений
   выравниваются на WARN-семантику апстрима: «ширины плывут» / «схлопываются», не «сбой
   рендера»); инлайновый `<note>` остаётся ERROR.
2. `validate_render.py`: новый детектор многострочного `<colgroup>` — ERROR
   (механика апстрима: открывающий тег, занимающий строку целиком); однострочная форма
   остаётся легальной (allowlist).
3. Всё прочее в `validate_render` не меняется (D7): th, multiple-images, unbalanced
   живут как есть до следующего цикла.

## Открытые предметы следующего цикла

1. th-правило: факт 200 + A/B-инфраструктура готовы — понижение по протоколу
   (стале-долг переносится в следующий цикл сознательно, D7).
2. tier-1 на живой цели: `pageUrlTemplate` — данные владельца; деградационные симптомы
   (unbalanced, multiple-images) судятся DOM-ассертами.
3. Выделенный каталог `render-probes` для постоянного прогона (runbook, раздел пуша) —
   текущий замер шёл по временному приёму в `gramax-user-docs` по санкции владельца.
4. Повторный замер при обновлении рендерера портала (дрейф-чувствительность класса 3).

## Инварианты

- Культура BR-021…024 применена: ни одного изменения вердикта без записи замера;
  «два неподтверждённых фикса подряд — стоп» не сработал — неподтверждённых фиксов не
  было вовсе (3 детектора не вошли, th не тронут).
- Код и запись — один коммит; правки вне двух классов D7 отсутствуют.
- Гигиена: литерал хоста цели в записи отсутствует (AC-114); токен в записях и логах
  отсутствует (NFR-081).
