## Перевод вардена ac-118 (NFR-084, ADR-0027 «Целевой состав --full»)

- Было: каждое упоминание render-quality в `scripts/check-gramax.sh`, включая комментарии, вне `--full`-блока — отказ; после добавления состава сюит в комментарий заголовка варден краснел бы на комментарии.
- Стало: судятся только исполняемые строки (первый непробельный символ — решётка комментария — исключается); упоминание render-quality в комментарии заголовка не «вне `--full`», исполняемая строка с прибором вне блока краснит по-прежнему. Сила изоляции `--fast` сохранена целиком (запрет исполнения усилен не был — комментарий никогда не исполнялся); красный варден остаётся триажем.

## Отклонения от буквы AC и что осталось нерешаемым

1. **Дом блока предусловий:** ADR-0008 (Решение 6, AC-009, RISK-001/002) прописывает Prerequisites и WARNING в `plugins/gramax/README.md`; FR-221(б) и задача gramax-o0q.10 кладут блок в корневой README с пометкой «плагинный README не проверялся». Стаб судит корневой README (буква AC-146); судить ли вдобавок плагинный — решение Dev/PM, стаб не заводится (не задвоить носители одним якорем).
2. **Число сюит 17:** текст ADR-0027 («Итог: … 16 сюит») ещё не отражает поправку PM (сюита gate-composition — последним шагом). Стабы ac-143 (нога 6) и ac-146 (число 17 в описании `--full`) кодируют поправку; при ратификации ADR-0027 в другой редакции число правится тем же коммитом, что и состав.
3. **Поток баннеров отказа:** ADR-0027 не закрепляет stdout/stderr для баннеров `RENDER_TARGET_UNREACHABLE` и `PLAYWRIGHT_PIN_UNRESOLVED` (сегодняшний `refuse()` печатает в stdout, обёртка uv — в stderr); стаб грепает объединённый вывод. Если при реализации баннер уйдёт только в файл отчёта — стаб честно красный, это дефект реализации, не стаба.
4. **Глубина маскировки rc (AC-144):** нога судит строку шага на хвост-подавление; косвенная индирекция (переменная с командой) не ловится — граница названа, глубже стаб не идёт (гейт читается человеком при ревью).
5. **Граница скана AC-150:** только `docs/30-requirements/*.md`; жирные определения в `docs/40-architecture/`, эпиках и сюитах контрактом AC-150 не названы — расширение скана решение владельца реестра.
6. **Ноги вне стаба:** настоящий зелёный `--full` на чистом дереве (AC-141) — доказательство координатора на приёмке; запись ночного отчёта от 2026-11-19 (AC-145, «исправлена или помечена») — процедурная, владелец PM; подключение индексной строки настоящего документа — координатор (правка `_index.md` исполнителю запрещена).
