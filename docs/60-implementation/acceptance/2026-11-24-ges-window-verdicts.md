# GES-окно живых проверок: вердикты «не проверено» по чек-листу — документарное закрытие (волна-4)

**Опоры:** `docs/00-project/epics/2026-11-24-wave4-tails-genesis-tree.md`,
`docs/60-implementation/acceptance/2026-11-18-plantuml-bpmn-at-design.md`,
`docs/00-project/adr/0015-root-index-inert.md`,
`docs/30-requirements/2026-11-18-writer-tail-480-requirement.md`

**Дата:** 2026-11-24. **Решение:** D12
[дерева волны-4](../../00-project/epics/2026-11-24-wave4-tails-genesis-tree.md) — окно живых
проверок в приложении закрывается документарно; в этой волне исполняется только сессия замеров
рендер-проб на портале. **Что эта запись есть:** именованная точка, где по каждому пункту
чек-листа стоит вердикт и причина. **Что её нет:** ни один пункт не исполнялся в живом
окружении, ни одно поведение движка здесь не подтверждено.

## Вердикты

| № | Пункт чек-листа | Вердикт | Причина | Что остаётся |
|---|---|---|---|---|
| 1 | Runtime-проба `<bpmn>` и Salt-макетов в живом окружении | не проверено | окно GES в волне-4 не выделялось (D12) | оговорка в CHANGELOG плагина и строка статуса в README плагина сохраняются |
| 2 | Расширения таблиц (aggregation, sort, colspan…) — BR-020, AC-102 | не проверено | нужна проба движка в живом окружении; из репозитория недоступна | слова-ключи расширений не проверяются валидатором; оговорка в CHANGELOG сохраняется |
| 3 | Живая сессия навыка plantuml: артефактные половины AC-051…AC-056, смоки AC-060 и AC-061 | не проверено | окно не выделялось | в приёмке plantuml-bpmn эти половины остаются «не проверено» |
| 4 | Визуальная проверка в приложении: корневой `_index.md`, вид битой ссылки, неразрешённая кросс-каталожная ссылка (ADR-0015) | не проверено | нужен просмотр в приложении | решение ADR-0015 остаётся в силе без визуального подтверждения |
| 5 | Поверхность только для GES: `showIf`, `mode`, `shuffleQuestions`, типы вопросов, `cover`; `<gallery>`, Gantt и палитры вне enum; ревизия BR-016 | не проверено | окно не выделялось | BR-016 не пересматривается |
| 6 | Регистрация каталога в GES и репоинт с `content/` на `docs/` в менеджере workspace | вне этого репозитория | внешняя зависимость: правка в другом репозитории, из дерева не исполняется и не проверяется | остаётся за владельцем этой зависимости |
| 7 | Версия движка на проду относительно пина `48592b36` | не проверено | прод недоступен из репозитория | замер 2026-11-24: `git ls-remote https://github.com/Gram-ax/gramax.git refs/heads/master` → `48592b36`, то есть master открытого репозитория равен пину |

## Условие возврата

Окно открывается снова по решению владельца. Тогда каждый вердикт «не проверено» заменяется
измеренным, а там, где действует протокол записи замера FR-196, — только его формой. До этого
смена вердиктов по пунктам 1–5 и 7 этой записью не производится.

## Последствия

- Оговорки CHANGELOG плагина по рендеру BPMN/Salt и расширениям таблиц остаются с основанием
  «окно не исполнено»; снимаются только измеренным вердиктом.
- Ни одно требование волны-4 не опирается на поведение, подтверждённое в живом GES: решения
  валидаторов волны-4 стоят на исходниках движка на пине и на замерах корпуса.
