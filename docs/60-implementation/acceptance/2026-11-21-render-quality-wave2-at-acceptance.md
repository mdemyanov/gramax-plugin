## Breaking change (внесекционная норма: скрипт гейта в дереве отсутствует)

**Понижение th-киллера ERROR → WARN — видимое пользователю поведение линтера.** Носитель
изменения — `plugins/gramax/CHANGELOG.md`, раздел **Unreleased → Changed** (посажено коммитом
`0b71ce2`): правило `<th>` понижено по повторному замеру факта рендера (дважды HTTP 200 на
боевой цели — записи замера волны-1 и волны-2; BR-021/FR-199). **Миграционный смысл:**
контент, который прежде блокировался ERROR по th (rc=1, «Тег `<th>` не поддерживается Gramax
→ HTTP 500»), теперь даёт warn («потенциальный киллер апстрима, не подтверждённый на этой
цели» — рекомендация, не констатация сбоя) и rc не красит; **семантика баланса не изменилась** —
несбалансированный `<th>` по-прежнему ERROR баланса (warn-киллер баланс не подавляет,
NFR-083); rc-контракт валидатора 0/1/2 не менялся; прочие киллеры (инлайновый `<note>`,
многострочный `<colgroup>`) остались ERROR.
