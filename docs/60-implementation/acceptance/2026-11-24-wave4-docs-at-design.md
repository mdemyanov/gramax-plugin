## Размещение по сюитам — решение QA-author

- **gate-composition** (бриф волны) — состояние корпуса `docs/` и корневых текстов: прогон
  приборов актуальности/TPL-69, конвенция статусов, согласие трёх корневых текстов, вердикты
  дайджеста. Прецедент — ac-149/ac-144 (CLI-прогоны приборов на `docs/`) и ac-146 (пины
  корневых текстов); предмет «документарное состояние дерева», не «поведение плагина».
- **plugin-contract** (бриф волны) — тексты плагина: README плагина (строгость плейсхолдеров,
  строка-указатель рецепта, строка статуса plantuml), SKILL.md comments-write (рецепт G11),
  периметр D9 (7 навыков + review-agent), запись вердиктов GES-окна судится тем же стабом
  (бриф волны: «the record itself can be judged by the same stub»).
- **writer-sync-470** — предмет сюиты по её README: «контент скилла writer» (SKILL.md и
  references/*.md). Оба стаба пиннят прозу writer: оговорка `:::` — по образцу уже
  запертой здесь legacy-оговорки `<cut>` (ac-077, тот же blocks.md), RECORD/POINTER — раздел
  «Ссылки» SKILL.md (смежный пин прозы SKILL.md — ac-006/ac-087). link-form-migration не
  выбрана: её предмет — механика классификации/миграции nav-спанов, а не проза writer.
- **export-skill** — документарный след навыка export: стаб пиннит обратную ссылку на
  требование export в RES-007 и датированные правки строк экспорта/портала (владелец
  контрактов навыка — ac-041…ac-050 той же сюиты).

Номера файлов = номера AC (правило сюит: ac-NNN = AC-NNN); сдвоенные AC — один стаб на пару
(AC-189/190 судятся одним прогоном прибора: «неопределим: 0» влечёт форму отказов, «устарел: 0»
— резолв путей; AC-191/192 — конвенция и её исполнение в requirements).

1. **Бриф называет AC-214 и AC-184 требования-соседа, но ни один из десяти пунктов брифа их не
