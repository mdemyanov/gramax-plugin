# Дерево решений генезиса: волна-2 калибровки прибора render-quality — боевой режим на живой цели

## Цель

Довести прибор render-quality до боевого режима на живой цели: повторный замер и судьба
th-правила по факту рендера, tier-1 DOM-ассерты на живой цели (шаблон страницы получен),
временные пробные страницы в живом каталоге, документарное закрытие волны. Волна-2 ведётся
поверх закрытой волны-1 (ACCEPT 16/16, коммит 718101b) и наследует её решения.

## Дерево решений

- **D1** Маршрут и класс Stage 0? → **решение:** эпик через генезис-интервью (2 раунда из
  5, фронтволна закрыта) в документарном контуре — `bin/store.sh` в репо нет (bd
  недоступен, расхождение названо, OPS-002); класс Stage 0 «прибор» назван владельцем
  после UNCLEAR-раунда: механика таблицы классов по полному тексту запроса даёт «роль»
  через случайную подстроку «рол» — известный дефект носителя AC-4a (фикс у владельца,
  не переобсуждается); замер по названному классу: perimeter 530 файлов / anchors 335
  файлов, тир full (пороги тира живут в отсутствующем `openspec/specs` — расхождение
  названо). **почему:** постоянная инструкция владельца «режим называет владелец»;
  прецедент — дерево волны-1 в том же адаптированном доме `docs/00-project/epics/`.
- **D2** Судьба th-правила? → **решение:** вердикт меняется только повторным замером
  против факта рендера на боевой цели (FR-196/FR-198): повторный 200 → понижение
  ERROR→WARN в `gramax-render-rules.json` (killers, tag `th`) и `validate_render.py`;
  подтверждённый отказ (ошибка/500) → правило остаётся ERROR без правки; правка кода +
  запись замера + адаптация затронутых AC сюит — одним циклом (решение 3 волны-1, урок
  lessons-learned); CHANGELOG-пункт в том же цикле. **почему:** раунд 1, Q1.1 + Q1.4;
  BR-021…024 нерушимы.
- **D3** tier-1 на живой цели? → **решение:** входит в волну — pageUrlTemplate получен:
  форма человекочитаемой страницы `{base}/{каталог}/{путь-страницы}`; живой пример-страница
  владельца зафиксирован в сессии и переносится в gitignore-конфиг (пример прибора
  предполагал `{base}/page/{catalog}/{slug}` — живая форма без сегмента `/page/`);
  без шаблона пункт откладывался бы листом с триггером «pageUrlTemplate получен» —
  триггер снят получением шаблона. **почему:** раунд 1 Q1.2 + раунд 2 Q2.1.
- **D4** Порядок и глубина волны? → **решение:** (1) повторный замер на боевой цели +
  судьба th одним циклом → (2) временные пробные страницы + постоянный конфиг + прогон
  прибора → (3) tier-1 на живой цели → (4) документарное закрытие: at-acceptance
  дополнение, README сюиты/runbook синхронно, уроки в журнал. **почему:** раунд 1 Q1.3
  (рекомендация PM принята владельцем).
- **D5** Пробные страницы на живой цели? → **решение:** временные страницы в живом
  каталоге пользовательской документации — санкция владельца на создание в сессии;
  отдельный выделенный каталог на портале не создаётся (упрощение против исходного плана
  хенда); слаг живого каталога и имена пробных страниц — в gitignore-конфиг; уборка
  временных страниц после замера входит в санкцию. **почему:** раунд 2 Q2.2; пуш на цель =
  разовая санкция в сессии (решение 4 волны-1), sync/push-навыки — никогда.
- **D6** Боевой доступ? → **решение:** baseUrl боевого портала назван владельцем и
  переносится в gitignore-конфиг по необходимости; токен волны-1 погашен, в конфиге пусто
  → свежий токен выпускается к фазе замера (открытый пункт OI-1, запрос в сессию по
  необходимости); литерал хоста и токен — только в gitignore-конфиг (ADR-0014, files-only;
  git-история не переписывается); в публичных файлах — параметрические плейсхолдеры.
  **почему:** раунд 2 Q2.3; решение 6 волны-1.
- **D7** Пуш 22 коммитов main → origin/internal (653f848 → 718101b)? → **решение:** после
  закрытия волны-2, отдельным актом владельца, вне скоупа эпика; одним пушем вместе с
  коммитами волны-2. **почему:** раунд 2 Q2.4 (вне скоупа волны).
- **D8** Унаследованные решения волны-1? → **решение:** генезис волны-1 финален (дерево
  волны-1: D1–D8, FR-187…198, ADR-0025 Accepted); sync/push-навыки — никогда;
  отложенные треки волны-1 (отдельный оракул-прибор, модуль поиска/контента портала,
  validate_structure) — не предлагать; BR-021…024 нерушимы; протокол калибровки
  FR-196/FR-198 действует в волна-2 без изменений. **почему:** хенд волны-2 — решения
  владельца от 2026-11-21 (не переобсуждаются).
