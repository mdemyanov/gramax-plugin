# ADR-0022: Навык export — шестой публичный скилл плагина gramax: плейсмент, релизная поверхность, контракт границы

**Status:** Accepted
**Date:** 2026-11-18
**Plugin:** gramax / marketplace

## Context

[RES-007](../../10-domain/research/2026-11-18-enterprise-server-skill-gap.md) фиксирует незакрытыми
зоны экспорта документации: `collaboration/export-docx-pdf/*` (шаблоны PDF/DOCX, UI-экспорт),
`deploy/export-ci-cd` (CI-стадия), `deploy/doc-portal/export-templates` (шаблоны портала),
`deploy/doc-portal/install/static-site-generator` (статический портал). Ни один из пяти навыков
плагина 4.6.0 (writer, comments-read, comments-write, mermaid, drawio) тему экспорта не упоминает.

Требование [Навык export — экспорт DOCX/PDF](../../30-requirements/2026-11-18-export-skill-requirement.md)
(FR-131…FR-139) оставляет плейсмент открытым вопросом 1: отдельный навык
`plugins/gramax/skills/export/SKILL.md` (кандидат по умолчанию, AC-041…AC-049 целены в него) либо
экспортный раздел/файл внутри `writer`.

Добавление публичного скилла меняет публичную поверхность плагина: по семантике ADR-0006 новый
скилл — additive minor (bump `plugin.json` и `marketplace.json`), а корневой
`.claude-plugin/marketplace.json` — публичный договор, правка которого без ADR запрещена красной
линией AGENTS.md. Прецеденты смены набора публичных скиллов через ADR — ADR-0008 (удаление
внутренних drawio-skills), ADR-0009 (drawio-stub); данный ADR симметричен им для добавления.

## Decision

### Решение 1 — FR-131: отдельный публичный навык `plugins/gramax/skills/export/`

Экспортная guidance-поверхность — отдельный навык, не раздел `writer`. AC-041…AC-049 требования
целены в этот путь, перецелевание не требуется.

Обоснование: (a) триггерные поверхности не пересекаются — FR-131 требует в `description` шесть
экспортных слов («экспорт», «DOCX», «PDF», «шаблон экспорта», «CI/CD», «статический портал»), их
встраивание в description `writer` ломало бы его триггерный контракт (ложные срабатывания на
CI/портал-запросы, где writer бессилен); (b) JTBD различны — авторинг контента против выгрузки
вовне; (c) дом держит норму «один навык — одна компетенция» (writer/mermaid/drawio/comments);
(d) объём правки writer при альтернативе сопоставим с новым файлом, но оставляет навык-монолит.
Кросс-связь — одна строка в «Ресурсы» writer-SKILL.md (description writer не меняется);
демаркация «Не для правки контента статей → gramax:writer» — в description export по паттерну
mermaid ↔ drawio.

### Решение 2 — релизная поверхность: minor 4.7.0, синхронный bump двух публичных файлов

- `plugins/gramax/.claude-plugin/plugin.json`: `version` → `4.7.0`, `description` упоминает export.
- `.claude-plugin/marketplace.json`: `metadata.version` → `4.7.0`, описание entry `gramax`
  дополняется навыком export. Этот ADR — разрешение на правку публичного файла (красная линия
  AGENTS.md).
- `plugins/gramax/CHANGELOG.md`: запись 4.7.0, секция Added.
- Исполнитель bump — Tech-writer в release-flow после Dev + зелёного QA-runner (ADR-0006).
- Номер 4.7.0 не резервируется жёстко: параллельные требования 2026-11-18 (plantuml-bpmn,
  validators-parity) могут претендовать на тот же минор; развод версий — по прецеденту ADR-0018,
  арбитр PM.

### Решение 3 — контракт границы: guidance-only, оговорка в самом description

Навык инструктирует и готовит артефакты (CSS-шаблон PDF, инструкцию `.docx`/`.dotx`, текст
CI-стадии, команды к исполнению); исполнение экспорта — Node.js/`gramax-cli` в окружении
пользователя или CI-раннера — навыком не гарантируется и не исполняется (NFR-055/BR-006
требования). Оговорка входит в `description` навыка: потребитель читает границу до первой
генерации — ожидания не строятся на исполнении. Прецедент паттерна «навык готовит — внешний
инструмент исполняет» — делегирующий drawio (ADR-0008). Граница — часть публичного контракта
навыка, поэтому фиксируется здесь, а не только в design-документе.

Sample-шаблоны файлами и скрипт-валидатор — отклонены (факт-гигиена BR-007: нераскрытые
RES-007 детали не изобретаются); детали — в design-документе, не часть этого ADR.

## Consequences

**Положительные:**

- Шесть компетенций — шесть навыков; триггерные контракты не размываются, роутинг Claude Code
  предсказуем.
- Additive minor: пользователи `gramax@4.x` получают обновление без breaking changes (ADR-0006).
- Граница исполнения проговорена в description — навык не порождает ложных ожиданий исполнения.
- AC-041…AC-049 применяются без перецелевания.

**Отрицательные / trade-offs:**

- Правится публичный `marketplace.json` — два файла версионруются синхронно; рассинхрон ловит
  manifest-coherence (suite `plugin-contract`, mitigation по ADR-0006).
- Шестой навык удлиняет описание entry в marketplace.json.
- Если PM отклонит плейсмент, ADR переписывается; риск принят — альтернатива нарушает триггерный
  контракт writer (Решение 1a).

**Mitigations:**

- Верификация фактов навыка (`npx gramax-cli --help`, апстрим-страницы) — на Dev-фазе по политике
  verify-before-include design-документа; неверифицированное — указателем на источник.
- Регистрация статей (требование, design, этот ADR) в `_index.md` — центрально выполняет PM.

## Alternatives Considered

- **Раздел/файл внутри `writer`** (`references/export.md` + правка description writer) — отклонён:
  шесть триггерных слов FR-131 в description writer дают ложные срабатывания на CI/портал-запросы;
  JTBD экспорта — не авторинг; семвер-невидимое наращивание монолита writer.
- **Новый entry в `marketplace.json`** (split) — отклонён: прецедент ADR-0001/ADR-0008 (split
  отклонён), экспорт — компетенция домена Gramax в границах того же плагина.
- **Новый публичный скилл без правки `marketplace.json`** — отклонён: публичный договор меняется
  фактически (скилл виден потребителям), красная линия требует ADR на правку.
- **Sample-шаблоны как файлы навыка / валидатор шаблонов** — отклонены: BR-007 (запрет изобретений
  сверх RES-007); `.dotx` бинарно и не авторится агентом; предмет валидатора вне дерева сканирования
  валидаторов плагина (ADR-0012).
