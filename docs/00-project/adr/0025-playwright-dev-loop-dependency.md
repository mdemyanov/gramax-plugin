# ADR-0025: Playwright в dev-контуре — питон-биндинг через uv без npm-поверхности, браузер вне репо, сетевой шаг в --full

**Status:** Draft (SA-авторство 2026-11-21; ратификация PM — на ревью эпика)
**Date:** 2026-11-21
**Plugin:** gramax

## Context

Генезис-дерево [Playwright в пайплайне разработки](../../00-project/epics/2026-11-21-playwright-render-quality-genesis-tree.md)
(D2, D5, D8) и требование [Прибор рендер-проб](../../30-requirements/2026-11-21-playwright-render-quality-requirement.md)
(FR-188…FR-190, FR-194, FR-195) вводят Playwright в dev-контур: пробы рендера
страниц-фикстур на живой цели и калибровка `validate_render` против факта портала.
Замер репо 2026-11-21: корневого `package.json` нет, npm-поверхности нет вовсе;
единственный драйвер инструментария — uv (гейты зовут `uv run`). Бриф явно открыл
вопрос «корневой `package.json` против scripts-local» как потенциально структурный.
Три позиции решения: дом зависимости, провижининг браузера, сетевой статус `--full`.
Исполнительская расшифровка (конфиг цели, отказы, модули, отчёт) —
[дизайн-документ](../../40-architecture/2026-11-21-playwright-render-quality-design.md).

---

## Решение 1 — дом зависимости: питон-биндинг через uv, npm-поверхность не вводится

Playwright входит как **питон-биндинг**, вызов строго через обёртку
`scripts/render-quality/probe.sh`: `uv run --with playwright==<pin> …`. Пин точной
версии — одна строка в `probe.sh`, номер фиксирует Dev на дату реализации.
Корневой `package.json`, lockfile и `node_modules` не появляются; скриптовая
логика прибора — Python (прецеденты: `validate_render.py`, апстрим-оракул
`scan-portal.py` — оба Python, RES-009 §1/§4).

## Решение 2 — браузер вне репо; «не прогрет» = именованный отказ

Бинарники chromium живут в штатном пользовательском кэше playwright
(`playwright install chromium`); в git не попадают, vendoring запрещён. Единственный
рычаг прогрева — `bash scripts/render-quality/warm.sh` (кэш uv + браузер +
`--check-env`). Неготовность именуется кодами `PLAYWRIGHT_UNAVAILABLE` /
`PLAYWRIGHT_NO_BROWSER`, rc≠0, подсказка называет рычаг (D8, прецедент ADR-159
`UV_OFFLINE`); офлайн-промах uv-кэша ловит обёртка в `probe.sh` по суженной
сигнатуре ADR-159. Тихий skip и «зелёный гейт без прогона» исключены.

## Решение 3 — `--full` становится сетевым шагом, `--fast` не затрагивается

Шаг render-quality в `scripts/check-gramax.sh` (`--full`-блок, после render-linter) —
первый сетевой шаг гейта: обращается к цели из gitignore-конфига (FR-195,
ADR-0014). Сетевая зависимость легализуется именованными отказами (Решение 2):
неготовность цели/браузера/кэша — красный гейт с именем и рычагом, не зелёный
пропуск. `--fast` остаётся офлайн и без прибора (NFR-078); состав шагов `--full`
только пополняется (NFR-079). Регистрация — после позеленения по TDD-цепочке
(FR-194).

## Решение 4 — механика конфига цели и фикстур ADR-достойной не признана

Путь/формат gitignore-конфига цели, env-переопределения, нарезка модулей, формат
фикстур и отчёта — исполнительские решения владельца SA (FR-188 прямо назначает
их SA); они живут в дизайн-документе и не закрепляются ADR. Этот ADR несёт только
структурный сдвиг контура.

---

## Consequences

**Положительные:** один язык прибора (Python: harness + валидатор + оракул-прецедент);
нулевая структурная цена в репо (нет npm, lockfile, node_modules); прогрев
идемпотентен и назван одним рычагом; отказы именованы на каждом уровне (uv-кэш,
пакет, браузер, цель).

**Отрицательные / trade-offs:** `--full` требует сети и прогретого окружения — на
непрогретой машине гейт красный (осознанный D8, не дефект); разовый объём
загрузки браузера (~сотни МБ) в пользовательский кэш; пин версии playwright —
ручная строка в `probe.sh` без lockfile-механики.

**Mitigations:** `warm.sh` как единый рычаг; суженная сигнатура uv-промаха
(ADR-159) ловит дрейф текста; стабы сюиты офлайн (stub-сервер) и не требуют сети.

## Alternatives Considered

- **Корневой `package.json` (npm-поверхность):** отклонено — второй пакетный
  менеджер в uv-only репо, структурная цена (lockfile, node_modules, гигиена
  коммитов) без выигрыша: скриптовая логика всё равно Python.
- **Node playwright с scripts-local `package.json`:** отклонено — та же
  npm-поверхность, только локализованная; два языка одного прибора.
- **Браузеры в репо (vendored/committed):** отклонено — красная линия vendoring
  без ADR, объём, дрейф версий; кэш пользователя решает.
- **Без ADR (решить в дизайне):** отклонено — сдвиг структурный: первый браузерный
  зависимость-класс и первый сетевой шаг `--full`; «почему нет package.json и
  откуда playwright» переживёт эпик.
