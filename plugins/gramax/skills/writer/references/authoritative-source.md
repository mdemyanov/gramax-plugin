# `writer` — authoritative источник Gramax-соглашений

`writer` — единственный authoritative источник Gramax-соглашений для проектов, подключивших
плагин `gramax`. Легитимно: локальный скилл, специфичный для конкретного проекта (конвенции
одного каталога `content/` — нейминг раздела, property одного домена), не входящие в общий
контракт Gramax. Нелегитимно: локальный скилл, переизлагающий общее Gramax-правило и
объявляющий себя приоритетным «при расхождении» над `writer` — это сигнал устаревания или
неполноты плагина, подлежащий разбору (issue/PR в `gramax-marketplace`), а не постоянная
архитектура.

## Обнаружение локального скилл-дубля

Grep-конвенция для ручного аудита (сопровождающим плагина — по подключённым проектам;
сопровождающим проекта-потребителя — по собственному дереву `.claude/skills/`):

```bash
grep -rliE 'дополняет.{0,15}gramax:writer|при расхожден.{0,20}(побежда|приоритет)' \
  **/skills/*/SKILL.md
```

Совпадение — сигнал, что в проекте уже заведён локальный скилл-дубль общего Gramax-правила.
Использовать как пункт чек-листа онбординга потребителя плагина и периодического аудита
сопровождающего `gramax-marketplace`. Конкретная форма проверки не единственная возможная —
грep-конвенция здесь достаточна для обнаружения, автоматизация (CI-гейт у потребителя) —
решение самого потребителя.
