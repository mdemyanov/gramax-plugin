# Источник кросс-каталожной ссылки

Кросс-каталожная документация: `other-catalog/path/to/file.md` (см. правило SKILL.md:213-220
— код-спан, не markdown-ссылка). Путь резолвится ВНЕ текущего `.doc-root.yaml`-каталога —
FR-085/AC-007: миграция не должна превращать этот код-спан в ссылку, несмотря на NAV-маркер
(«см.») рядом.
