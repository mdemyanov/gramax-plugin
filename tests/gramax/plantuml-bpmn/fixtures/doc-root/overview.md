# Обзор модуля

Стандартная статья-фикстура suite'а plantuml-bpmn (кейс AC-051/AC-053/AC-060:
`target_page` = обычный md-файл; после авторства рядом появляется
`<page-slug>-<diagram-slug>.puml`, а в статье — тег-ссылка).

Статья намеренно не содержит ни диаграммных тегов, ни fenced-блоков:
фикстура не должна делать будущие проверки зелёными по пустоте.
