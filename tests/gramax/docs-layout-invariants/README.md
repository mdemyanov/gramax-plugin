# tests/gramax/docs-layout-invariants

Живая сюита инвариантов раскладки (ADR-0029, Решение 2): пять инвариантов инверсии
раскладки документации, оставшихся действительными после её завершения — AC-003…AC-007
требования инверсии раскладки. Стабы — копии архивных оригиналов
`tests/gramax/archive/docs-migration/` с именованными отличиями (см. «Отношение к архиву»);
сам архив не редактируется.

## Статус

Стабы — гарды состояния: инверсия завершена, ассерты держатся на каждом коммите.
Красные состояния возможны у ног, судящих живые инструменты (ac-005 — нога валидатора
`docs/`; ac-003 — в окне приват-прохода волны-4, пока замаскированные строки не попали
в коммит; ac-005 — пока статьи других ролей не зарегистрированы в индексах).

## Запуск

    bash tests/gramax/docs-layout-invariants/run.sh                      # вся сюита
    bash tests/gramax/docs-layout-invariants/ac-003-no-content-pointers.sh   # одиночный

ROOT резолвится через `git rev-parse` — проверки идут от корня дерева. Без `lib/` и
`fixtures/`: каждый скрипт самодостаточен (дом-паттерн архивного оригинала).

## Стабы и инварианты

| Файл | Инвариант |
|------|-----------|
| `ac-003-no-content-pointers.sh` | литерал `content/` вне исключений Решения 3 ADR-0021 не встречается (файловые и строчные классы) |
| `ac-004-no-deleted-pointers.sh` | нет указателей на артефакты, удалявшиеся при инверсии (имена не цитируются в живых файлах; RECORD выживших записей учтён) |
| `ac-005-gates-rekeyed.sh` | `.nauta-gates.yaml` действует на `docs/`, `documentaryCircuit` отсутствует, валидатор зелёный |
| `ac-006-layout-map-resolves-docs.sh` | карта раскладки в `AGENTS.md` адресует все шесть домов через `docs/` |
| `ac-007-single-doc-root.sh` | ровно один корень каталога — `docs/.doc-root.yaml`; модель свойств объединена; корневой индекс поглотил роль корневого |

Подключение к `--full` — шаг `docs-layout-invariants` сразу после `nauta-integration`
(`scripts/check-gramax.sh`; ADR-0029, Решение 2). Статусы сюит судит
`tests/gramax/gate-composition/ac-143-suite-statuses.sh`.

## Отношение к архиву

Копии; отличия от архивных оригиналов именованы и перечислены целиком:

1. строка 2 каждого стаба — адрес живой сюиты и происхождение копии (ADR-0029, Решение 2);
2. `ac-003` — адрес собственного исключения: вместе с архивным каталогом исключается и
   эта сюита (case-глоб `docs-layout-invariants/*`; соседняя архивная строка `archive/*`
   уже покрывала старый адрес);
3. `ac-004` — то же исключение дословной формой
   `grep -qE "^tests/gramax/(archive/docs-migration|docs-layout-invariants)/"`;
4. `ac-003` — правило кл.6 для чужих репозиториев-потребителей переведено на токен
   `<локальный-корень>/` (приват-проход волны-4, D8 ADR-0030: имена замещены токенами,
   слэш после токена сохранён; приватные имена в стабе не цитируются);
5. `ac-003` — удалено мёртвое исключение для скрипта-артефакта, удалённого при инверсии
   (путь не цитируется: упоминание удалённого пути — резидуальная ссылка; его ловит
   сюита `orphan-references`);
6. этот README переписан для живой сюиты: архивный описывал двенадцать стабов приёмки
   миграции и нёс литералы переехавших каталогов.
